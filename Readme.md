# ⚡ EV Charging Demand Analytics | Power BI

An interactive **Power BI analytics solution** designed to analyze electric vehicle (EV) charging demand, energy consumption, charging costs, vehicle behavior, charger utilization, station performance, and location-level demand.

The project transforms EV charging data into meaningful insights through interactive dashboards, KPI tracking, advanced DAX calculations, and data security features.

---

## 📊 Project Overview

The **EV Charging Demand Analytics** dashboard provides a comprehensive view of EV charging network operations from January to March 2025.

It enables users to monitor charging activity, understand energy demand patterns, evaluate operational efficiency, compare vehicle charging behavior, and identify high-performing charging stations and locations.

The dashboard incorporates interactive features such as **bookmarks, slicers, tooltips, drill-through navigation, page navigation, and Row-Level Security (RLS)** to deliver an intuitive analytical experience.

### 3. Vehicle Analysis

Evaluates charging behavior, energy consumption, charging duration, and performance across different vehicle categories.



**Vehicle Categories:**

### 4. Station & Location Analysis

Provides insights into station-level performance and geographical charging demand.



**Key Analysis:**

## ⚙️ Interactive Dashboard Features

The dashboard includes several interactive capabilities to improve usability and analytical exploration.

| Feature                  | Description                                                                |
| ------------------------ | -------------------------------------------------------------------------- |
| Bookmarks                | Enable interactive panels and predefined dashboard views                   |
| Filters & Slicers        | Filter information by date, vehicle, and location                          |
| Tooltips                 | Display additional contextual information on hover                         |
| Drill-through            | Navigate from summary-level insights to detailed analysis                  |
| Page Navigation          | Move between the four dashboard pages                                      |
| Row-Level Security (RLS) | Restrict data visibility based on configured user access                   |
| Settings Panel           | Includes Executive View, Detailed View, Reset Filters, and About Dashboard |

| User Profile             | Displays current user, role, location access, and RLS status               |

## 🎯 Project Objectives

The primary objective is to transform raw EV charging data into an interactive business intelligence solution that helps monitor and evaluate:

- Charging demand and session activity
- Energy consumption patterns
- Charging costs and operational expenses
- Charging and waiting duration
- Vehicle category performance
- Charger utilization and performance
- Charging station efficiency
- Location-level energy demand

---

## 🔐 Data Security – Row-Level Security (RLS)

Row-Level Security (RLS) is implemented to control data visibility based on configured user roles and location-level access.

The dashboard also includes a user profile panel that displays:

- Current user
- Assigned role
- Authorized location access
- RLS status

This provides a structured approach to managing access to charging network information.
